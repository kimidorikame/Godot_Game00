# レイアウト方向メモ（構想）

> これは構想メモ。実装はまだしない。実装時期は M5 ポリッシュ以降を想定。
> 予算・工数の都合で、当面は最小実装（現状のレイアウト）のまま進める。

## 目指す方向

案A/C系（会話と味付けが同居するレイアウト）。
特に **案C（全画面会話＋味付けパネルがせり出す形）が本命**。

## 狙いたい体験

鍋に水やベースを足したり、椀に味付けしている最中も、客がぽつぽつ喋っていて
「場が生きている」空気を出したい。

参考: VA-11 Hall-A の雰囲気（バーテンダーが作業しながら客と会話する間合い）。

## 声を使わない前提での "喋ってる感" の出し方

声を使わない代わりに、以下の手段でテキストベースの臨場感を出す想定:

- 味付け操作中も会話ウィンドウを画面に残し、合間に短いセリフを差し込む
- 操作への反応セリフを用意する（例: 水を足すと「薄めるのかい」）
- タイプライタ表示・立ち絵の微揺れで「今喋ってる」感を出す
