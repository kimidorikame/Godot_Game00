# 困窮脱出動線メモ（構想）

> これは構想メモ。実装はまだしない。実装時期は M4（7日ループ・セーブ）以降を想定。
> M4のセーブ／日またぎ状態管理と同時に設計・実装する。

## 解決したい問題

M3で実装した「その日限り」残り湯（`base_zanryu`）だけでは、
「所持金0 ＆ ベース素材0」の状態が翌日以降も継続してしまうケースを救えない。
休業しても状態が変わらないため、脱出不能な詰み状態になりうる。完全な詰みを回避する
脱出ハッチが必要。

## 案: クズ食材ベース

- 移動先選択に「クズ野菜」「くず骨」「水」を取得できる場所を追加（水は月初に一括支払い）
- 仕込み時、これらから「クズ食材ベース」（昨夜の鍋の残り ＋ 水 ＋ クズ野菜/くず骨）を作成可能にする。ステータスは最低クラスのベースになる
- クズ食材の取得は「所持金0 ＆ ベース素材0」のときのみ許可する（平時に使える無限リソースにはしない＝ソフトフェイル救済に限定）

## なぜM4以降か（実装前提）

1. 「昨夜の鍋の残りを持ち越す」＝鍋 volume/attrs の日またぎ保存が必要 → セーブ実装（M4）と密結合
2. 「所持金0＆素材0の継続」判定＝日またぎ状態管理が前提
3. 取得条件フラグも同様に日サイクルの上に乗る

## 残り湯（M3）との役割分担

M3で実装した「その日限り残り湯」（`base_zanryu`）とは役割が異なる別システム。

| | 残り湯（M3・実装済み） | クズ食材ベース（本メモ・M4以降） |
|---|---|---|
| 役割 | 単日の買い忘れ救済 | 継続的困窮からの脱出動線 |
| 状態 | 毎日リセット（永続の残量を持たない） | 取得条件つき・持ち越しあり（鍋の残り継承） |
